# Files the dashboard embeds

`lightweight-charts.standalone.production.js` is TradingView Lightweight Charts™ 5.3.0,
unmodified, from the npm package `lightweight-charts`
(https://unpkg.com/lightweight-charts@5.3.0/dist/lightweight-charts.standalone.production.js,
198,600 bytes, sha256 `M4piXs5SxbhfsCbiItrV0PNl90UGCvv66WvakWNhQuk=` as the registry lists it).
The dashboard writes it into each page that has a price chart, so the pages need nothing
from the network.
